# Attendance-Shortage-Predictor---Minor-Project---I

DESCRIPTION:
In many educational institutions, students fail to meet the minimum attendance requirement due to the lack of continuous monitoring and late realization of attendance shortages. Most colleges still rely on manual or fragmented attendance systems where students only become aware of their shortage near the examination period. This often leads to academic penalties, detention, or loss of exam eligibility. There is a need for a simple and effective system that helps students track their attendance regularly and predicts shortages in advance so that corrective action can be taken on time.


OBJECTIVES:
To calculate the current attendance percentage of students accurately.

To identify whether a student is meeting the minimum attendance requirement.

To predict attendance shortage in advance based on current and remaining lectures.

To inform students about the number of classes required to reach the minimum attendance criteria.

To reduce academic risk by enabling early awareness and better attendance planning.


SOLUTION:
The proposed solution is a web-based Attendance Shortage Calculator that allows students to enter subject-wise attendance details such as total lectures conducted and lectures attended. The system automatically calculates the attendance percentage and compares it with the minimum required threshold (e.g., 75%). If a shortage is detected, the system predicts and displays the number of future classes the student must attend to recover the shortage. The platform provides a simple dashboard for students to monitor their attendance status regularly, helping them make informed decisions and avoid last-minute academic issues.


TECH STACK:
FRONT-END -> HTML5, CSS, JS

BACK-END -> PYTHON (FLASK)

DATABASES -> MySQL,MongoDB
